## [C] Контекст

Необходимо сверстать страницу ![alt text](../references/order-page.png). Кнопку "Промокод" не добавляй.

1. Изменить существующий localStorage для корзины, нужно добавить туда также список опций к тому или иному товару, причем дефолтные также должны быть, поскольку у каждого товара бэкенд ожидает выбранные опции, включая дефолтные.

2. Позиции с разными модификаторами должны суммироваться отдельно.

3. Если в корзине у нас только один товар и пользователь нажимает кнопку "-" товар удаляется из списка и из локального хранилища.

4. При клике пользователя на "+" у товара добавляется еще один товар с теми же модификаторами, которые есть у этого товара

## [О] Результат/Цель - что должно быть

При клике пользователем на кнопку "добавить в заказ" позиция появляется на странице "мой заказ" где он может удалить его, или же удалить все позиции в списке, а также добавить увеличить уже добавленные товары, а само модальное окно с модификаторами плавно идет вниз (закрывается). На иконке "мой заказ" добавляется небольшой счетчик, показывающий сколько позиций добавлено в корзину. При случайном обновлении добавленные товары не исчезают.
